# Описание проекта 

Данный проект представляет из себя веб-сервер, реализующий функциональность планировщика задач. В нем разработаны следующие возможности:
+ создания и хранения задач;
+ создания задач с правилом повторения. Можно создавать задачи, повторяющиеся каждый день, каждый определенный день недели, каждое определенное число определенного или каждого месяца и т.д;
+ редактирования параметров задач.

# Инструкция по запуску кода локально

Для начала нужно разместить у себя локально проект. Для этого выберите директорию и выполните следующую команду в интерфейсе командной строке.

```bash
git clone https://github.com/hardius/go_final_project.git
```

Далее через CLI перейдите в корневую папку проекта и выполните следующую команду:

``` bash
go run main.go
```

После выполнения этой команды сервер будет запущен. Чтобы испытать функционал планировщика, откройте в вашем браузере http://localhost:7540/.

Можно также указать переменные окружения для установки номера порта, имени базы данных, а также пароля. Указывать их нужно перед запуском самой программы.

``` bash
export TODO_PORT=*номер порта*
export TODO_DBFILE=*имя базы данных*
export TODO_PASSWORD=*пароль*
```

При установке пароля можно будет испытать аутентификацию через пароль.

# Инструкция по запуску тестов


Файл *settings.go*** должен содержать следующие параметры

``` go
var Port = 7540

var DBFile = "../scheduler.db"

var FullNextDate = true

var Search = true

var Token = ``
```

Далее, находясь в корневом каталоге проекта, для запуска тестов выполняем следующую команду:

``` bash
go test ./tests
```

Чтобы запустить тесты с поддержкой аутентификации нужно в *setting.go* присвоить значение переменной `Token` значение токена, которое сервер возвратил из `/api/signin` и которое хранится в куке `token`.

# Инструкция по запуску и сборке проекта через докер 

Находясь в корневой папке проекта, выполняем следующую команду.

``` BASH
 docker build -t todo .
```

Далее, когда наш образ проекта Docker собран, запускаем наш контейнер, выполняя следующую команду:

``` BASH
docker run -p 7540:7540 todo
```
